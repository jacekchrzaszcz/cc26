## Lvar to quadruples

We work with languages Lvar (simple programs with variables)

```
P ::= S | S ; P
S := print(E) | id = E;
E ::= C | C + E | E - C
C ::= L | C * L | - L
L ::= A | (E) | input_int()
A ::= id | n
```

and Lqua (quadruples)

```
P ::= S | S ; P
S := print(R) | id = R;
R ::= A | A + A | A - A | A * A | input_int()
A ::= id | n
```

Translate from Lvar to Lqua:

- `print(40+2)`
- `print(input_int())`


Translate Lvar ->  Lqua -> x86

A.
``` python
a = input_int()
b = input_int()
c = input_int() + 1
print(b*b - 4*a*c)
print(b // c)
print(c % a)
```

B.
```python
v = 1
w = 42
x = v + 7
y = x
z = x + w
print(z + (- y))
```
