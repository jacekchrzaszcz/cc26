## Parameters and local variables

Translate to x86:


```python
def add(x, y) -> int:
  return x+y

def f1(x) -> int:
  y = input_int()
  return x+y 
  
def f2(x) -> int:
  y = input_int()
  print(y)
  return x+y

def f3():
  x = input_int()
  y = input_int()
  if x > y:
    print(42)
  else:
    print(44)

def f4(a,b,c,d):
  print(a*d - b*c)

def f5(n):
  return 6 if n>0 and n-1<9 else 7

def f8(x1,x2,x3,x4,x5,x6,x7,x8):
  return x1+x2+x3+x4+x5+x6+x7+x8

def g():
  print(f(1,2,3,4,5,6,7,8))
```

In the book, functions with >6 parameters use tuples.
A more conventional way is to pass them on the stack - use this to translate f8 and g

## Move-biasing

Look closely at register allocation for the function *add* above
and analyse how move-biasing can help avoid code like

```att
    movq %rdi, %rcx
    movq %rsi, %rdx
    movq %rcx, %rax
    addq %rdx, %rax
    jmp add_conclusion
```
